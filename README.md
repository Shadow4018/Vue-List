# Vue-List (Users List)

Вебзастосунок на Vue 3 + TypeScript для перегляду списку користувачів: картки з контактними даними та хобі, фільтрація за статтю й повноліттям, сортування за ім'ям і віком. Навчальна лабораторна робота №3 (компоненти, шаблони, директиви Vue).

🔗 **Демо проєкту:** https://vue-list-one.vercel.app

## Стек
* **Frontend:** Vue 3 (Composition API, `<script setup>`), TypeScript
* **Стилізація:** CSS (scoped-стилі компонентів, CSS-змінні для кольорів карток), Flexbox & Grid
* **Робота з даними:** локальний JSON-файл (`src/data/user.json`), типізовані дані
* **Збірка:** Vite
* **Якість коду:** ESLint (`eslint-plugin-vue`, пресет `flat/recommended`), `vue-tsc` для перевірки типів

## Основний функціонал
* Список із 10 користувачів у вигляді карток: стать, ім'я, місце проживання, email, телефон, фото, дата народження, хобі.
* Умовний рендер: вік у картці показується лише для користувачів старших за 18 (`v-if`).
* Список хобі через `v-for` з `:key`.
* Колір картки залежить від вікової групи (`:class`, об'єктний синтаксис): до 18 — синій, 18–30 — зелений, 31–50 — жовтий, понад 50 — фіолетовий.
* Кнопка «Показати / Сховати деталі» (`v-show`).
* Фото з динамічним `:src` та `:alt`.
* Фільтр за статтю (всі / чоловіки / жінки) та фільтр «18+».
* Сортування за ім'ям і віком (за зростанням і спаданням); працює разом з активними фільтрами.
* Кнопка «Очистити все» скидає фільтри й сортування.
* Лічильник «Показано: N з M» і повідомлення «Список юзерів пустий», якщо за фільтрами нікого не знайдено (`v-if` / `v-else`).

## Як запустити локально
1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/Shadow4018/Vue-List.git
   ```
2. Перейдіть у папку проєкту та встановіть залежності:
   ```bash
   cd Vue-List/Vue-List/vue-users-lab
   npm install
   ```
3. Запустіть сервер для розробки (за замовчуванням http://localhost:5173):
   ```bash
   npm run dev
   ```

## Корисні команди
| Команда | Призначення |
| --- | --- |
| `npm run dev` | сервер розробки |
| `npm run build` | перевірка типів і production-збірка |
| `npm run preview` | локальний перегляд збірки |
| `npm run type-check` | перевірка типів (`vue-tsc`) |
| `npm run lint` | ESLint з автовиправленням |

## Примітки
* Вік у картці показується при `age > 18`, а фільтр «18+» враховує `age >= 18`, тому 18-річний користувач потрапляє у фільтр, але без поля «Вік» у картці (так сформульовано в завданні).
* Компоненти `Users.vue` та `App.vue` мають однослівні назви за вимогою завдання, тому для них вимкнено правило `vue/multi-word-component-names`.
* Додаткові нотатки та відповіді на контрольні питання лабораторної — у [`Vue-List/vue-users-lab/README.md`](./Vue-List/vue-users-lab/README.md).
