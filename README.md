# Лабораторна робота №3 — Vue 3: компоненти, шаблони, директиви

Vue 3 + TypeScript (Composition API, `<script setup>`) + Vite + ESLint.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run type-check   # vue-tsc
npm run lint         # eslint
npm run build
```

## Що реалізовано

| Завдання | Де |
| --- | --- |
| Картка юзера: gender, name, location, email, phone, picture, dob | `src/components/UserCard.vue` |
| `v-if` — вік лише якщо > 18 | `UserCard.vue` |
| `v-for` — список хобі (`:key`) | `UserCard.vue` |
| `:class` (об'єктний синтаксис) — minor / young / adult / senior | `UserCard.vue` + `getAgeGroup()` |
| `v-show` — показати/сховати `details` | `UserCard.vue` |
| 10 юзерів, `:src` + динамічний `:alt`, фото в `public/users` | `src/data/user.json`, `Users.vue` |
| «Список юзерів пустий» (`v-if` / `v-else`) | `Users.vue` |
| Фільтр за статтю, фільтр 18+, сортування (ім'я/вік ↑↓), «Очистити все» | `Users.vue` + `src/utils/users.ts` |

Сортування не ламає фільтри: спершу `filterUsers`, потім `sortUsers`
(`getVisibleUsers`), усе в одному `computed`.

Вікові групи: до 18 — minor (синій), 18–30 — young (зелений),
31–50 — adult (жовтий), понад 50 — senior (фіолетовий).

## Нотатки

- `public/users/user-*.png` — **заглушки** з ініціалами. Замініть їх реальними
  фото з тими самими іменами (або змініть `picture` у `user.json`).
- `Users.vue` і `App.vue` названі однослівно, бо цього вимагає завдання; для них
  у `eslint.config.ts` вимкнено `vue/multi-word-component-names`.
- Вік у картці показується при `age > 18` (буквально за завданням), а фільтр
  «18+» бере `age >= 18`, тому 18-річний користувач потрапляє у фільтр, але
  без поля «Вік» у картці. Якщо викладач очікує інакше — змініть умову в `UserCard.vue`.

## Відповіді на контрольні питання

1. **Компонент** — самодостатній блок UI з власним шаблоном, логікою і стилями,
   який можна перевикористовувати. Застосунок — дерево компонентів із кореневим `App.vue`.
2. **SFC** — файл `.vue`, що об'єднує в одному місці `<template>`, `<script>`
   (чи `<script setup>`) і `<style>` (зокрема `scoped`).
3. **Шаблон** — HTML-подібна розмітка, що компілюється у render-функцію. У ній
   доступні інтерполяція `{{ }}`, директиви, JS-вирази, виклики методів/computed, компоненти.
4. HTML статичний; шаблон Vue — декларативно прив'язаний до стану: підтримує
   інтерполяцію, директиви, компоненти й оновлюється при зміні даних.
5. **Директиви** — спеціальні атрибути з префіксом `v-` (`v-if`, `v-for`, `v-bind`, `v-on`…),
   що реактивно змінюють DOM. Синтаксис: `v-name:argument.modifier="вираз"`.
6. **`v-bind`** прив'язує атрибут/проп до виразу: `<img :src="user.picture" :alt="name">`.
7. Різниці немає: `:src` — скорочений запис `v-bind:src`.
8. **`v-if`** додає/видаляє елемент із DOM (умовний рендер); `v-else-if` — додаткова
   умова, `v-else` — запасна гілка (мають іти одразу після `v-if`). **`v-show`** завжди
   рендерить елемент і лише перемикає CSS `display`. `v-if` дорожчий при перемиканні, `v-show` — при першому рендері.
9. **`v-for`** рендерить список за масивом/об'єктом/діапазоном. `:key` має бути
   унікальним і стабільним (id, не індекс), щоб Vue коректно перевикористовував вузли.
   Не комбінуйте `v-if` і `v-for` на одному елементі (див. style guide).
10. **Реактивність** — Vue відстежує читання реактивного стану (`ref`, `reactive`) і при його
    зміні автоматично перерендерює лише ті частини шаблону, що від нього залежать.
